# CareerZone X 浏览器采集扩展

## 安装（Edge / Chrome）

1. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）。
2. 打开右上角“开发人员模式”。
3. 点“加载解压缩的扩展”，选择本目录 `extension/`。
4. 点扩展图标，填 `http://127.0.0.1:8000`。
5. 本机默认关闭令牌校验，令牌可以留空；如果网站设置里开启了校验，再生成并填入。

## 使用

1. 手动打开 BOSS/猎聘/智联/51JOB/鱼泡的**职位详情页**（推荐）或搜索结果页。
2. 等页面加载完。
3. 点扩展“采集当前页”。

## 边界

- 只读取当前标签页 DOM，不自动点击、滚动、翻页。
- 不读取招聘网站账号密码，不调用平台私有 API。
- 不破解验证码/风控。
- 列表页只能抓到卡片摘要；详情页的 AI 分析更准。
- 平台条款可能限制自动化采集，使用者自行承担风险。

## 已知限制

招聘网站 DOM 经常改版，选择器可能失效。优先依赖 JSON-LD（JobPosting）；如果没有 JSON-LD，再退回通用选择器。失效时改 `background.js` 里的 `extractPage` 选择器即可。
