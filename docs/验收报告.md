## 4. 当前已知问题

1. 采集完整 JD 仍需用户在原站详情页点一次扩展；服务端不做自动抓取。
2. 单次采集最多 1000 条；自动翻页不做；浏览补全需用户滚动。
3. AI 每页最多初筛 300 条；1000 条页面不会全部分析。
4. 管理员密码固定且弱，只适合本机。
5. 本机 WSL MySQL 不稳定，默认 SQLite。
6. 公网/手机访问按 docs/华为云部署指南.md 执行；尚未实际购买/部署云主机。
7. 官方 API 只有适配器/文档，没有平台授权，不会自动爬取。
8. 登录页 3 个小游戏为本地 JS，不联网。
9. 旧头像可能在之前清理测试目录时丢失；现在需重新上传，默认占位已加。

## 5. 验收结论

功能可本机运行，核心流程闭环：  
注册 → 审核 → 画像 → 采集 → 筛选 → AI 初筛 → 详情两轮 → 收藏/历史 → 导出。

**结论：本机自用验收通过；公网部署需另做安全加固。**
