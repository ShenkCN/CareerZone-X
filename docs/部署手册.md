# 部署手册（本机 Windows）

> 版本：2026-11-18  
> 适用：当前这台 Windows 电脑，或同配置新电脑。跨电脑完整步骤见同目录 `从零部署到另一台电脑.md`。

## 1. 运行环境

- Windows 10/11 x64
- Python **3.11**（项目 `.venv` 即基于 3.11）
- Edge 或 Chrome（装采集扩展）
- 默认数据库：SQLite，无需安装数据库
- 可选：MySQL 8（不推荐在当前 WSL 环境使用，见第 8 节）
- DeepSeek API Key（没有 Key 时规则初筛可用，两轮分析不可用）
- 磁盘：项目 + 依赖约 500MB；上传/日志另算

## 2. 首次安装

```powershell
cd "D:\CareerZone X"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\pip.exe install -r requirements.txt
```

RAG 可选依赖（本机有 DLL 拦截时不要装）：

```powershell
.\.venv\Scripts\pip.exe install -r requirements-rag.txt
```

## 3. 配置 .env

复制模板：

```powershell
Copy-Item .env.example .env
notepad .env
```

本机推荐关键值：

```env
APP_HOST=127.0.0.1
APP_PORT=8000
API_BASE_URL=http://127.0.0.1:8000
DATABASE_URL=sqlite:///./storage/careerzone.db
DEEPSEEK_API_KEY=你的Key
VECTOR_ENABLED=true
VECTOR_TRY_MODEL=false
IMPORT_MAX_JOBS=1000
IMPORT_TOKEN_REQUIRED=false
IMPORT_REQUIRE_SESSION=false
ADMIN_USERNAME=Shenk
ADMIN_INITIAL_PASSWORD=你的管理员密码
ADMIN_INITIAL_ANSWER=你的8位密保答案
```

管理员初始密码只在**首次建库**时读取；已有库不会覆盖。

## 4. 建库和启动

```powershell
.\.venv\Scripts\python.exe -m scripts.init_db
.\start.ps1
```

或双击 `start.bat`。

- 用户端：http://127.0.0.1:8501
- API：http://127.0.0.1:8000
- 健康检查：http://127.0.0.1:8000/health

`start.ps1` 是幂等的：已在运行会直接退出，不会重复起进程。

## 5. 登录自启动（已安装）

项目暂停时已移除当前用户的登录自启动。恢复方法：运行 `scripts/install_autostart.ps1`。原快捷方式位置：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\CareerZone X.lnk
```

它调用：

```powershell
powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File "D:\CareerZone X\start.ps1"
```

安装/移除：

```powershell
.\scripts\install_autostart.ps1
.\scripts\remove_autostart.ps1
```

说明：

- 重新安装后登录自动起 API + Streamlit，不自动打开浏览器；
- 如果登录时 8501 已经被别的进程占用，脚本会认为已运行并退出；
- 不会启动 WSL，也不依赖 MySQL；
- 重启电脑后等 10—20 秒再开 http://127.0.0.1:8501。

## 6. 浏览器扩展

1. 登录用户端 → 设置 → 浏览器采集 → 下载扩展 ZIP；
2. 解压得到 `careerzone-extension`；
3. Edge 打开 `edge://extensions`，开启开发人员模式；
4. 加载解压缩的扩展，选择文件夹；
5. 点扩展图标，API 地址填 `http://127.0.0.1:8000`，保存；
6. 不需要令牌；可勾选“浏览时自动补全当前可见 JD”（可选）；
7. 打开招聘页面，点“采集当前页”；
8. 开启自动补全时，滚动列表/打开详情页会自动补全当前可见 JD；
9. 回职位板点“搜索”。

扩展只读当前页，不自动翻页。列表页只抓摘要；详情页才能抓完整 JD。
可开启“浏览时自动补全当前可见 JD”，它不会主动滚动/翻页。

## 7. 数据目录和备份

```text
storage/careerzone.db        SQLite 主库
storage/uploads/             简历/头像
storage/logs/                运行日志
storage/chroma/              向量库
storage/exports/             导出文件
storage/private/             初始凭据等私有文件
```

备份（服务停止后复制）：

```powershell
Copy-Item storage\careerzone.db "D:\backup\careerzone-$(Get-Date -Format yyyyMMdd).db"
Copy-Item storage\uploads -Recurse "D:\backup\uploads"
Copy-Item storage\chroma -Recurse "D:\backup\chroma"
```

## 8. MySQL（可选，不默认）

`.env`：

```env
DATABASE_URL=mysql+pymysql://careerzone:密码@127.0.0.1:3306/careerzone_x?charset=utf8mb4
```

切换：

```powershell
.\.venv\Scripts\python.exe -m scripts.switch_db mysql
.\.venv\Scripts\python.exe -m scripts.init_db
```

注意：当前 WSL MySQL 曾被外部进程反复停止，导致随机 500。没有稳定 MySQL 前，保持 SQLite。

## 9. 常见问题

### 8501 打不开

```powershell
Get-NetTCPConnection -LocalPort 8501
Get-Content storage\logs\api.err.log
```

如果 8501 被旧进程占用，结束旧 Streamlit 再 `start.ps1`。

### API 500

先看：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
Get-Content storage\logs\api.err.log -Tail 50
```

### DeepSeek 不工作

- 看 `.env` 的 `DEEPSEEK_API_KEY`；
- 看 `LLM_ENABLED=true`；
- 管理员 → 系统后端 → 向量/模型状态；
- 没有 Key 时列表仍可用规则初筛，但两轮分析会明确报错。

### 扩展采集失败

- API 地址必须是 `http://127.0.0.1:8000`；
- 页面必须是 http/https；
- 招聘页面加载完再点；
- 旧扩展要重新加载 0.4.0。

## 10. 云服务器提醒

当前只监听 `127.0.0.1`，手机/其他电脑访问不到。  
部署云服务器需要：

- 改 `APP_HOST=0.0.0.0`；
- Nginx/Caddy 反代 8501/8000；
- HTTPS；
- 防火墙只开 80/443；
- 重新评估采集条款、管理员密码、Cookie 安全；
- 不建议直接把 8501/8000 暴露公网。
- 公网/华为云购买与 Nginx/HTTPS/systemd 步骤见 docs/华为云部署指南.md。
- 多用户：扩展要带登录 Cookie；云上设 IMPORT_REQUIRE_SESSION=true。
