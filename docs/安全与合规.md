# 安全与合规说明

> 版本：2026-11-18  
> 结论先说：这是本机/小团队多用户工具，默认只监听 127.0.0.1。公网部署按 docs/华为云部署指南.md，并换管理员强密码。

## 1. 认证与会话

- 密码：Argon2id 哈希；
- 普通用户注册后 `pending`，管理员通过才能登录；
- 登录失败 5 次锁定 15 分钟（可配置）；
- 注册/忘记密码/催审批有 IP 频率限制；
- 登录成功返回随机会话令牌，数据库只存哈希；
- 普通用户会话 12 小时；管理员 4 小时；
- Streamlit 刷新页面用 Cookie 恢复会话，退出登录清除 Cookie；
- 管理员登录：密码 + 5 分钟签名挑战令牌 + 密保答案；
- 修改密码会撤销该用户所有会话；
- 浏览器扩展优先读取当前登录 Cookie，避免多用户采集串号。

### Cookie 的取舍

当前 Cookie 由前端 JS 写入，不是 HttpOnly。原因是 Streamlit 单页应用没有后端登录回调，刷新恢复需要浏览器可读令牌。  
本机自用可接受；**公网必须改为服务端 HttpOnly + Secure + SameSite Cookie**。

## 2. 密码策略

当前（用户明确要求放宽）：

- 账号 5—15 位，字母/数字；
- 密码 6—20 位，纯数字/纯字母/混合均可；
- 只接受常见 ASCII，不允许空格/中文/emoji。

风险：纯数字/弱密码容易被猜。  
这是单机便利性取舍；公网应恢复大小写+数字+符号，并加 2FA。

## 3. 管理员

- 固定账号 `Shenk`；
- 固定密码（用户指定）且不可自助修改；
- 密保问题 + 答案；
- 固定密码是已知风险：泄露只能改数据库哈希或重建管理员；
- 本机可以使用；公网部署前必须在首次建库时设置强密码，或重建管理员哈希。

## 4. 采集合规边界

- 扩展只在用户点击时读取**当前页可见 DOM**；
- 不自动登录、不自动翻页、不滚动、不点击下一页、不破解验证码；
- 可选的“浏览补全”只读当前可见详情，仍需用户滚动/打开页面，扩展不主动操作页面；
- 不做服务端爬虫；
- 单次最多 1000 条；

### 多用户采集隔离

- 职位 Job 全局共享；采集关系在 JobCapture；
- 用户 A 清空只标记 A 的 cleared_at，不删除 Job；B 没有自己副本也看不到；B 自己采过则保留；
- 用户可申请恢复，管理员按用户/批次恢复；
- 旧版硬删除无法恢复，这是升级前的历史限制。

### 扩展身份

- 扩展从网站 http://127.0.0.1:8501 读 czx_session Cookie，发 Bearer；
- 云上必须把扩展网站地址改为域名，并同步 manifest 主机权限；
- 云上设 IMPORT_REQUIRE_SESSION=true，未登录采集直接 401。
- 不保证平台条款允许自动化采集，用户需自行判断；
- 采集的是招聘页面公开信息，仍可能包含个人信息；只在本机保存，不对外分享。

## 5. 数据与隐私

本机存储：

- 账号（哈希）、画像、手机号/邮箱；
- 简历 PDF/Word、头像；
- 职位原文、AI 分析、Token 用量；
- 浏览/收藏/反馈。

措施：

- 上传大小限制（简历 10MB、头像 2MB）；
- 文本清洗/HTML escape，避免采集内容 XSS；
- 日志不记录密码/API Key；
- `.env` 不提交版本库；
- 默认无云同步。

用户应：

- 不把 `.env`、`storage/private`、数据库发给别人；
- 换电脑时通过安全渠道传 `.env`；
- 定期备份 `storage/careerzone.db`。

## 6. 数据传输

- 浏览器扩展 → 本机 FastAPI：HTTP 127.0.0.1；
- Streamlit → FastAPI：HTTP 127.0.0.1；
- FastAPI → DeepSeek：HTTPS；
- 没有第三方登录、没有云端数据库。

公网部署必须（完整步骤见 docs/华为云部署指南.md）：

- HTTPS；
- 反向代理；
- 访问控制；
- 重新开启导入令牌；
- 限流、审计、备份。

## 7. AI 风险

- 列表初筛可能不准；
- 两轮分析只在 JD 完整时允许；
- 列表采集/短 JD 会被 422 拒绝，避免模型凭标题编造；
- AI 结论不是招聘方承诺，投递前必须回原站核对；
- Token 用量可在管理员控制台查看。

## 8. 已知风险清单

| 风险 | 现状 | 建议 |
|---|---|---|
| 管理员密码固定且弱 | 本机使用 | 不公网；泄露后重建哈希 |
| Cookie 非 HttpOnly | 刷新免登录 | 公网改服务端 Cookie |
| 纯数字密码 | 用户要求 | 公网恢复强策略 |
| 采集条款 | 用户点击/滚动，可选浏览补全 | 不自动翻页；需用户主动浏览 |
| SQLite 单文件 | 默认 | 定期备份；不要多进程写 |
| MySQL 不稳定 | WSL 外部停止 | 稳定前保持 SQLite |
| AI 误判 | 有免责声明 | 两轮分析 + 原站核对 |
