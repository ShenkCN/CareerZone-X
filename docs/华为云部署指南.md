# CareerZone X 华为云极简部署手册

> 
> 适用场景：华为云 ECS + 公网 IP，Nginx 反向代理，仅暴露 80/443 端口
> 服务架构：FastAPI（本地 127.0.0.1:8000）+ Streamlit（本地 127.0.0.1:8501）

---

## 1. 云资源准备

表格

| 资源 | 规格建议 | 是否必备 |
| --- | --- | --- |
| 弹性云服务器 ECS | 2 核 4G，Ubuntu 22.04/24.04，系统盘 40G 以上 | 是 |
| 弹性公网 IP EIP | 5Mbps，绑定至 ECS | 是 |
| 安全组 | 入方向开放 22、80、443 端口 | 是 |
| 域名 + SSL 证书 | 按需选购，国内域名需 ICP 备案 | 否 |

> 
> ⚠️ 禁止将 3306、8000、8501 端口直接开放到公网

---

## 2. 系统环境初始化

SSH 登录服务器后执行：

```
apt update && apt upgrade -y
apt install -y nginx git unzip python3 python3-venv python3-pip
```

若服务器内存 ≤ 1GB，添加 2GB 交换分区：

```
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' | tee -a /etc/fstab
```

---

## 3. 上传并解压项目

本地终端上传项目压缩包：

```
scp 本地路径/CareerZoneX-src.zip root@公网IP:/opt/
```

服务器端解压：

```
mkdir -p /opt/careerzone
cd /opt/careerzone
unzip /opt/CareerZoneX-src.zip
```

---

## 4. 配置 .env 文件

```
cp .env.example .env
nano .env
```

核心配置项（按需修改）：

```
APP_ENV=production
APP_HOST=127.0.0.1
APP_PORT=8000
APP_SECRET_KEY=64位随机密钥
API_BASE_URL=http://127.0.0.1:8000
DATABASE_URL=sqlite:///./storage/careerzone.db
DEEPSEEK_API_KEY=你的API密钥
ADMIN_USERNAME=管理员账号
ADMIN_INITIAL_PASSWORD=强密码
```

生成随机密钥命令：

```
python3 -c "import secrets; print(secrets.token_hex(32))"
```

## 5. 虚拟环境与数据库初始化

```
cd /opt/careerzone
python3 -m venv .venv
.venv/bin/pip install -U pip
.venv/bin/pip install -r requirements.txt
mkdir -p storage
.venv/bin/python -m scripts.init_db
```

## 6. 配置 systemd 常驻服务

### API 服务

```
cat >/etc/systemd/system/careerzone-api.service <<'EOF'
[Unit]
Description=CareerZone X API
After=network.target

[Service]
WorkingDirectory=/opt/careerzone
ExecStart=/opt/careerzone/.venv/bin/python -m scripts.run_api
Restart=always
RestartSec=3
User=root

[Install]
WantedBy=multi-user.target
EOF
```

### UI 服务

```
cat >/etc/systemd/system/careerzone-ui.service <<'EOF'
[Unit]
Description=CareerZone X UI
After=network.target careerzone-api.service

[Service]
WorkingDirectory=/opt/careerzone
ExecStart=/opt/careerzone/.venv/bin/python -m streamlit run frontend/app.py --server.address 127.0.0.1 --server.port 8501 --server.headless true
Restart=always
RestartSec=3
User=root

[Install]
WantedBy=multi-user.target
EOF
```

启动服务并设置开机自启：

```
systemctl daemon-reload
systemctl enable --now careerzone-api careerzone-ui
```

## 7. Nginx 反向代理

### 方案 A：纯 HTTP（无域名，IP 直接访问，推荐先测试）

```
cat >/etc/nginx/sites-available/careerzone <<'EOF'
server {
    listen 80;
    server_name _;
    client_max_body_size 20m;

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 300s;
    }
}
EOF
```

启用配置并生效：

```
ln -sf /etc/nginx/sites-available/careerzone /etc/nginx/sites-enabled/careerzone
rm -f /etc/nginx/sites-enabled/default
nginx -t
systemctl reload nginx
```

### 方案 B：HTTPS（有域名时使用）

1. 先将域名 A 记录解析到服务器公网 IP
2. 申请免费 SSL 证书：

```
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

## 8. 验证与访问

1. 浏览器访问 `http://公网IP`（HTTPS 则访问 `https://你的域名`）
2. 查看服务运行状态：

```
systemctl status careerzone-api careerzone-ui
```

## 9. 数据备份

```
systemctl stop careerzone-api careerzone-ui
mkdir -p /opt/backup
cp storage/careerzone.db /opt/backup/careerzone-$(date +%F).db
systemctl start careerzone-api careerzone-ui
```

---

## 10. 关键注意事项

1. 中国大陆境内服务器绑定域名，需完成 ICP 备案后方可正常访问
2. 管理员账号必须设置强密码，禁止使用弱口令
3. 禁止直接将 8000、8501 端口暴露至公网
4. 用户简历、联系方式等个人信息需做好权限管控与加密备份
