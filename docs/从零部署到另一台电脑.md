# 从零部署到另一台电脑（完整步骤）

> 适用：Windows 10/11 新电脑，想从零跑起 CareerZone X。  
> 目标：复制源码 → 装 Python 依赖 → 配 `.env` → 建库 → 启动 → 浏览器打开 8501。  
> 默认 SQLite，不需要 MySQL、WSL、Docker。  
> 版本 0.4.0：多用户采集隔离、管理员账号管理、按批恢复、登录小游戏、官方 API 适配器已在包内。

---

## 0. 先明确要带走什么

### 必须带走

- 源码目录（`backend`、`frontend`、`scripts`、`extension`、`tests`、`docs` 等）
- `requirements.txt`
- `start.ps1` / `start.bat`
- `.env`（含 DeepSeek Key、管理员初始密码；**不要发公开群**）

### 不要带走

- `.venv`：每台电脑重新建，否则路径/二进制不兼容
- `__pycache__`、`.pytest_cache`、`.ruff_cache`
- `storage/logs`
- `dist` 旧压缩包

### 是否带历史数据

| 需求 | 做法 |
|---|---|
| 全新开始 | 不带 `storage/careerzone.db`；新库自动建表/管理员 |
| 保留职位、用户、画像 | **停止两端服务**后复制 `storage/careerzone.db` |
| 保留简历/头像 | 复制 `storage/uploads` |
| 保留向量索引 | 复制 `storage/chroma`（可选，缺失会重建） |

> 复制数据库前一定先停止 API 和 Streamlit，避免 WAL/写入不一致。

## 1. 旧电脑：打包源码

### 方式 A：使用脚本（推荐）

项目根目录执行：

```powershell
.\scripts\package_release.ps1
```

生成：

```text
D:\CareerZone X\dist\CareerZoneX-src.zip
```

这个包**不含** `.env`、数据库、上传文件。

### 方式 B：手动打包

只压缩这些：

```text
backend/
frontend/
scripts/
extension/
tests/
docs/
.streamlit/
pyproject.toml
requirements.txt
requirements-dev.txt
requirements-rag.txt
start.ps1
start.bat
README.md
.env.example
.gitignore
```

### 迁移 `.env`

`.env` 里有 API Key 和管理员初始密码，**单独通过 U 盘/私密传输**，不要放进公开压缩包。

### 迁移数据库（可选）

先停止：

```powershell
# 如果在运行，先关掉 Streamlit 窗口，再结束 API
Get-Process python | Where-Object { $_.Path -like "*CareerZone X*.venv*" } | Stop-Process
```

复制：

```powershell
Copy-Item "D:\CareerZone X\storage\careerzone.db" "D:\transfer\careerzone.db"
Copy-Item "D:\CareerZone X\storage\uploads" "D:\transfer\uploads" -Recurse
Copy-Item "D:\CareerZone X\storage\chroma" "D:\transfer\chroma" -Recurse
```

## 2. 新电脑：先装环境

### 2.1 操作系统

- Windows 10/11 x64
- 建议至少 8GB 内存、2GB 空闲磁盘
- Edge 或 Chrome

### 2.2 安装 Python 3.11

下载 Python 3.11 x64：

```text
https://www.python.org/downloads/windows/
```

安装时勾选：

- Add python.exe to PATH
- Install pip

验证：

```powershell
python --version
```

应显示 `Python 3.11.x`。

> 不要用 Python 3.13/3.14 直接跑；部分依赖轮子可能不兼容。项目当前 `.venv` 是 3.11。

### 2.3 安装 Edge

Windows 自带；没有就用官网安装。扩展只在桌面 Edge/Chrome 加载。

### 2.4 可选：MySQL 8

默认 SQLite 不需要。只有想用 MySQL 才装；当前 WSL MySQL 在旧机器不稳定，新机建议先用 SQLite 跑通。

---

## 3. 新电脑：解压和建虚拟环境

把源码解压到：

```text
D:\CareerZone X
```

路径有空格可以，但不要放进 OneDrive 同步目录（SQLite 文件可能被锁）。

打开 PowerShell：

```powershell
cd "D:\CareerZone X"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -U pip
.\.venv\Scripts\pip.exe install -r requirements.txt
```

如果网络慢，可加国内镜像（示例）：

```powershell
.\.venv\Scripts\pip.exe install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

RAG 可选（本机可能被 DLL 策略拦截，不是必需）：

```powershell
.\.venv\Scripts\pip.exe install -r requirements-rag.txt
```

---

## 4. 新电脑：配置 .env

### 4.1 从旧电脑复制

把旧电脑的 `.env` 放到：

```text
D:\CareerZone X\.env
```

### 4.2 没有旧 .env：从模板新建

```powershell
Copy-Item .env.example .env
notepad .env
```

至少改这些：

```env
APP_NAME=CareerZone X
APP_ENV=development
APP_HOST=127.0.0.1
APP_PORT=8000
APP_SECRET_KEY=换成一串随机64位十六进制
API_BASE_URL=http://127.0.0.1:8000

DATABASE_URL=sqlite:///./storage/careerzone.db
DB_ECHO=false

DEEPSEEK_API_KEY=你的Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
LLM_ENABLED=true

VECTOR_ENABLED=true
VECTOR_TRY_MODEL=false
EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5
CHROMA_DIR=storage/chroma

ADMIN_USERNAME=Shenk
ADMIN_INITIAL_PASSWORD=你的管理员密码
ADMIN_SECURITY_QUESTION=CareerZone X 安装时生成的 8 位管理员暗号是什么？
ADMIN_INITIAL_ANSWER=你的8位答案

ALLOWED_ORIGINS=http://127.0.0.1:8501,http://localhost:8501,http://127.0.0.1:8000,http://localhost:8000
IMPORT_MAX_JOBS=100
IMPORT_TOKEN_REQUIRED=false
IMPORT_REQUIRE_SESSION=false
```

生成随机 secret（任选）：

```powershell
python -c "import secrets; print(secrets.token_hex(32))"
```

### 4.3 安全

- 不要把 `.env` 上传 GitHub；
- 不要把 DeepSeek Key 发群里；
- 如果旧 Key 泄露过，先撤销/换新；
- 管理员初始密码只在**首次建库**读取；已有数据库不会覆盖。

## 5. 新电脑：建库和启动

```powershell
cd "D:\CareerZone X"
.\.venv\Scripts\python.exe -m scripts.init_db
.\start.ps1
```

或双击 `start.bat`。

看到：

```text
API 已就绪：http://127.0.0.1:8000
用户端启动中：http://127.0.0.1:8501
```

浏览器打开：

```text
http://127.0.0.1:8501
```

检查：

```text
http://127.0.0.1:8000/health
```

返回 `{"status":"ok","database":true,...}`。

## 6. 新电脑：导入历史数据（可选）

先启动一次让目录生成，然后停止两端。

把旧电脑的：

```text
storage\careerzone.db
storage\uploads\
storage\chroma\
```

覆盖到新电脑对应位置。

再启动：

```powershell
.\start.ps1
```

注意：

- 已有数据库的管理员密码/密保仍以旧库为准，`.env` 里的初始值不会覆盖；
- 如果旧库是 MySQL，需要先在旧机导出 SQL 再导入新机；
- SQLite 备份要停服务后复制。

---

## 7. 新电脑：装采集扩展

1. 登录用户端；
2. 设置 → 浏览器采集 → 下载扩展 ZIP；
3. 解压出 `careerzone-extension`；
4. Edge → `edge://extensions` → 开发人员模式；
5. 加载解压缩的扩展，选文件夹；
6. 扩展 API 地址填 `http://127.0.0.1:8000`；
7. 网站地址填 `http://127.0.0.1:8501`（扩展要读当前登录 Cookie，多用户才能分清 A/B）；
8. 本机令牌默认关闭；扩展会优先带登录态，未登录才退回本机单用户；
9. 可勾选“浏览时自动补全当前可见 JD”；
10. 打开招聘页面，点“采集当前页”。

采集后回职位板点“搜索”。扩展单次最多 1000 条，不自动翻页；可开启浏览补全。

## 8. 登录自启动（可选）

安装当前用户登录自启动：

```powershell
.\scripts\install_autostart.ps1
```

会在：

```text
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\CareerZone X.lnk
```

创建快捷方式，登录后隐藏启动 `start.ps1`。

移除：

```powershell
.\scripts\remove_autostart.ps1
```

注意：

- 不自动打开浏览器；
- 启动后等 10—20 秒再访问 8501；
- 如果 8501 已被占用，脚本会直接退出，不会重复起进程；
- 不需要 WSL 自启动。

---

## 9. 手机/其他电脑访问（公网）

本机版只监听 127.0.0.1，手机访问不到。  
要部署到华为云 ECS 给多人注册使用，按 [华为云部署指南](华为云部署指南.md) 操作：

- 买 ECS + EIP + VPC/安全组；
- Nginx 反代 8501 和 8000；
- HTTPS；
- 防火墙只开 80/443；
- 云上设 `IMPORT_REQUIRE_SESSION=true`，并换掉管理员弱密码；
- 扩展网站地址改成你的域名，并同步改 manifest 主机权限。

不要把 8501/8000 直接暴露到公网。

## 10. 常见问题

### `.\start.ps1` 报“禁止运行脚本”

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\start.ps1"
```

或直接双击 `start.bat`。

### 8501 打不开

```powershell
Get-NetTCPConnection -LocalPort 8501
Get-Content storage\logs\api.err.log -Tail 50
```

先结束旧 Streamlit，再启动。

### 8000 健康检查失败

```powershell
Get-Content storage\logs\api.err.log -Tail 100
```

常见：`.env` 格式错、端口被占、数据库路径无权限。

### 安装依赖报 DLL/权限错误

- 确认 64 位 Python 3.11；
- 不要用系统全局 Python 装到项目外；
- 先只装 `requirements.txt`，不要装 `requirements-rag.txt`；
- 本机 `VECTOR_TRY_MODEL=false`。

### 采集扩展报错

- API 地址必须 `http://127.0.0.1:8000`；
- 页面必须 http/https；
- 旧扩展要重新加载 0.4.0；
- 招聘页面加载完再点。

### 管理员密码不对

- 已有数据库以数据库为准；
- 确认 `.env` 初始密码只在首次建库时生效；
- 忘记只能改数据库哈希或重建管理员，不能自助改。
